# Thimoli — code pour Claude

Instantané privé du 26 septembre 2026 de l’application d’apprentissage du tamoul.

Commencer par [le guide de reprise](thimoli/CLAUDE_VERSION_LEGERE.md), puis consulter [l’état actuel](thimoli/ETAT_ACTUEL.md) et [les derniers retours utilisateur](thimoli/RETOURS_TEST_UTILISATEUR.md).

Le dossier [`thimoli/`](thimoli/) contient les sources HTML, CSS et JavaScript, les contenus texte, les tests et les documents de travail. Les images, polices et fichiers audio sont exclus de cette version légère ; leurs références doivent être conservées. Cet export ne permet donc pas, seul, un aperçu graphique et sonore complet.

Les modifications sont à restituer sous forme de fichiers modifiés ou de patch, pour intégration au projet complet. Ce dépôt ne constitue pas un déploiement du site et n’actualise pas l’application du PC automatiquement.

Le [manifeste SHA-256](thimoli/MANIFEST-SHA256.json) décrit les 89 fichiers de l’instantané original. Les médias et originaux restent conservés sur le PC. Les droits audio, documents juridiques et validations pédagogiques ne sont pas considérés comme terminés.

Pour utiliser ce dépôt avec Claude, connecter le compte GitHub dans Claude et autoriser l’accès à **ce dépôt privé uniquement**. Une simple URL ne rend pas les fichiers privés accessibles.
