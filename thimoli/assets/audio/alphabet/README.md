# Alphabet audio additions

193 neural Tamil recordings supplement the pre-existing 54 recordings for the 247 native signs (12 vowels, 18 consonants, aytam, and 216 combinations).

Generated 2026-09-23 using ta-IN-PallaviNeural, rate -8%, pitch +2Hz. Filenames are stable SHA-256-derived names, never positional snippet IDs. The complete index is ../alphabet-index.js. Existing recordings and manifest were not reassigned.

These are synthetic recordings, not recordings by a Tamil teacher. They need pronunciation review before educational release, particularly the isolated syllable ரூ, which may be expanded by the synthesizer as a currency abbreviation. Browser playback tests do not validate pronunciation.
